## 🌟 Proyecto Integrador Destacado: [Sistema de Gestión de Gimnasios](./Unidades/Unidad%206/Tarea%206.2)

Ubicado en **`Unidades/Unidad 6/Tarea 6.2`**, implementa el diseño físico completo en SQL Server normalizado hasta 3FN/FNBC:
* **[01_schema_ddl.sql](./Unidades/Unidad%206/Tarea%206.2/01_schema_ddl.sql):** Esquema relacional DDL (10 tablas, llaves primarias `IDENTITY`, foráneas, restricciones `CHECK` e índices únicos filtrados).
* **[02_data_inserts.sql](./Unidades/Unidad%206/Tarea%206.2/02_data_inserts.sql):** Inserción secuencial de registros representativos respetando la integridad referencial.
* **[03_queries_dml.sql](./Unidades/Unidad%206/Tarea%206.2/03_queries_dml.sql):** Consultas analíticas (`JOIN`, `GROUP BY`, `HAVING`) y pruebas controladas con `TRY/CATCH`.
* **[Manual de Ejecución](./Unidades/Unidad%206/Tarea%206.2/README.md):** Guía paso a paso para clonar y ejecutar en SSMS.
